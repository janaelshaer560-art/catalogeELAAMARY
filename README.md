# كتالوج العمارى للأثاث

كتالوج واجهة أمامية ثابتة يقرأ المجلدات والصور مباشرة من Google Drive. لا توجد قاعدة بيانات أو لوحة إدارة.

## إعداد Google Drive

1. استخدمي المجلد الرئيسي المضبوط مسبقًا في `drive-config.js`.
2. أنشئي داخل المجلد الرئيسي مجلدًا لكل قسم رئيسي، مثل: `غرفة نوم`، `غرفة اطفال`، `صالون`، `انتريه`، `ركنه`، `غرفة سفره`.
3. داخل مجلدات الغرف، أنشئي مجلدات فرعية لأنواع الأثاث، مثل `سرير`، `دولاب`، `كومود`، `سراحه`، `بف-كرسى`، `مرايا`، `شفونيره`، `وحدة ادراج`، `مكتب`، `كرسى`، `نيش`، `بوفيه`، `ترابيزه`. ارفعي صور كل نوع داخل مجلده.
4. الأقسام التي لا تحتوي أنواعًا فرعية، مثل `صالون` و`انتريه` و`ركنه`، يمكن رفع صورها مباشرة داخل مجلد القسم. ويمكن إنشاء مجلدات فرعية لها إذا رغبتِ في تقسيم التصميمات.
5. لإضافة قسم رئيسي أو نوع أثاث جديد، أنشئي مجلدًا بالاسم المطلوب في المستوى المناسب؛ سيكتشفه الكتالوج تلقائيًا دون تعديل الكود. لإنشاء قسم رئيسي مستقل أضيفي مجلدًا داخل المجلد الرئيسي.
6. لإضافة غلاف ثابت لأي بطاقة قسم أو تصنيف، ارفعي صورة الغلاف مباشرة داخل مجلدها وسمّيها `cover.jpg` أو `غلاف.jpg`. تُستخدم كغلاف للبطاقة ولا تظهر ضمن صور المعرض. إذا لم تضعي صورة بهذا الاسم، يختار الموقع أول صورة متاحة تلقائيًا.
7. اجعلي المجلد الرئيسي وجميع مجلدات الصور قابلة للعرض من **أي شخص لديه الرابط**.
8. من Google Cloud Console، فعّلي Google Drive API وأنشئي مفتاح API. قيّديه بعنوان موقع Vercel `https://elaamarycatalog.vercel.app/*`، وأضيفي `http://localhost:8765/*` إذا كنتِ تختبرين محليًا. اجعلي Google Drive API الخدمة المسموح بها.
9. في Vercel، أضيفي المفتاح الجديد كمتغير `GOOGLE_DRIVE_API_KEY`. لا تضعيه في `drive-config.js` ولا ترفعيه في commit.
10. افتحي الموقع عبر استضافة أو خادم محلي بعنوان `http://` أو `https://`؛ فتح `index.html` مباشرة كملف لا يعمل مع قيود نطاق مفتاح API.

يجلب الكتالوج اسم كل ملف ومعرّفه ونوعه من Drive، ويعرض الصور تدريجيًا عند ظهورها على الشاشة. تُخزّن قوائم المجلدات مؤقتًا في الذاكرة لمدة خمس دقائق؛ كما يوجد زر **تحديث الصور** لتجاوز مدة التخزين وإعادة الجلب فورًا. حذف ملف أو إضافته في Drive ينعكس بعد التحديث أو انتهاء مدة التخزين المؤقت.

## نشر GitHub Pages

استخدام هذا المستودع مع GitHub Pages اختياري؛ موقع الإنتاج الحالي مستضاف على Vercel.

## نشر Vercel

إعداد `vercel.json` يشغّل `node build.js` ويستخدم `dist` كمجلد النشر. في مشروع Vercel المرتبط بالمستودع، أضيفي `GOOGLE_DRIVE_API_KEY` ضمن **Settings → Environment Variables** لبيئتي Production وPreview حسب الحاجة، ثم أعيدي النشر. ينشئ build ملف `drive-config.js` داخل مجلد النشر من متغير البيئة دون حفظ المفتاح في Git. المفتاح سيكون متاحًا لزوار الموقع من المتصفح؛ لذلك قيّديه بنطاق `https://elaamarycatalog.vercel.app/*` وبـ Google Drive API فقط.
